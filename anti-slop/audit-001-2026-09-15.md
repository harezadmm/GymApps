## Temuan

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM,
Quality Lock = LOW.

### HIGH

**1. Angka karangan ditampilkan seolah data asli — R-17, R-38**
Nilai-nilai ini tidak berasal dari catatan mana pun dan tidak ditandai placeholder:
- `home_screen.dart:69,71,73` — `18.4 t`, `+3`, `4d`
- `home_screen.dart:49` — berat badan `78.4 kg`
- `stats_screen.dart:320` — `+8.8% · 12 wk` (klaim tren tanpa deret data)
- `stats_screen.dart:361` — `target 75.0 kg`
- `history_screen.dart:49` — `$demoSessionsThisYear sessions this year`
- `profile_screen.dart:139,141,143` — `90 s`, `15 s`, `90%` sebagai setelan aktif
- `routine_editor_screen.dart:165` — `120 s`
Ini tell paling kuat di seluruh app: layar terlihat hidup padahal belum ada
datanya. Perbaikan: hitung dari catatan nyata, atau tandai jelas sebagai contoh.

**2. Kontrol mati — R-26, C-2**
16 pemanggilan `_todo()` dan 12 `onPressed: () {}` / `onTap: () {}` kosong.
Yang terlihat pengguna: Units, Default rest, Rest-pause, Deload factor, Effort
scale, Week starts on, Gym A/B, Add equipment profile, Export, Import, Force
sync, Theme, Accent colour, About, BUILD MY OWN, tombol Skip di beranda, pil
berat badan, ikon folder di header Workout.
Tidak ada label "Coming soon" yang terlihat; snackbar baru muncul setelah ditekan.

**3. Em dash di teks UI — R-02**
5 string (×2 bahasa) memakai `—`:
`strings.dart:104,220,234,269` dan `workout_screen.dart:267`.
Plus `'—'` sebagai glif placeholder kolom Prev di `session_screen.dart:239,574`
(ini lebih ringan — glif data, bukan prosa, tapi tetap masuk aturan).

**4. Tap target di bawah 44 pt — R-03**
- `widgets.dart:481` `SquareIconButton` 42×42 — dipakai di header Workout & Stats
- `rest_timer.dart:562` tombol preset 38×38
- `session_screen.dart:313` tombol FINISH tinggi 38
- `onboarding_screens.dart:406`, `workout_screen.dart:389` tombol dialog tinggi 42
Tangan berkeringat di gym adalah kasus pakai yang sebenarnya; ini bukan teori.

**5. Kontras di bawah WCAG AA — R-25**
Token `text3` `#5A6275`:
- di atas `surface` `#141925` → **2.88:1** (gagal normal & large)
- di atas `bgNested` `#0E1220` → **3.05:1** (gagal normal, lolos large)
Dipakai untuk teks di `home_screen.dart:154` (`+N more`, 12 px) dan badge PR di
`history_screen.dart:114` (9.5 px). Sisanya ikon, yang juga idealnya ≥3:1.
Token lain lolos: `text2` 5.84:1, tombol aksen 9.99:1, baris selesai 8.0:1.

**6. Tidak ada error state — R-27, C-4**
Hanya Library yang menangani kegagalan, dan itu pun menampilkan
`${snap.error}` mentah ke pengguna. Home, Session, Rest, Rest timer, Profile,
dan Routine editor tidak punya empty/loading/error sama sekali.
Stats punya loading + empty yang baik ("Membaca sesimu…", "Belum ada set
tercatat di rentang ini") — itu contoh yang benar, tinggal ditiru.

**7. Identitas palsu terlihat seperti asli — R-23, R-38**
`profile_screen.dart` menampilkan `hariz@example.com` dan avatar inisial `HZ`
tanpa penanda bahwa ini contoh.

**8. Setelan Theme ada tapi hanya satu tema yang dikirim — R-21, R-34**
Baris "Tema · Gelap" di Profil menjanjikan pilihan; tidak ada `ThemeMode`,
`darkTheme`, atau `Brightness.light` di seluruh `lib`. Gelap sendiri punya
alasan sah untuk app gym (dipakai di ruangan remang, layar dekat mata), jadi
pilihannya: hapus barisnya, atau bangun toggle-nya.

**9. Akses non-mouse belum digarap — R-32**
2 `Semantics()` di seluruh app. Home, Stats, History, Profile, dan Finish punya
**0 tooltip** pada tombol ikon-saja. Tidak ada indikator fokus kustom.
Untuk app sentuh ini soal VoiceOver/TalkBack, bukan Tab.

**14. Palet dasarnya masih default AI — R-01, R-20, pertanyaan kunci**
*Ditambahkan setelah hariz menolak PASS awal saya. Dia benar.*

Yang saya tes di putaran pertama: ada gradient atau tidak, berapa jumlah warna.
Keduanya lulus. Yang **tidak** saya tes: apakah warnanya sebuah keputusan.

Hue tiap token (dihitung, bukan dikira):

| token | hex | hue |
|---|---|---|
| bg | `#080B12` | 222.0 |
| bgNested | `#0E1220` | 226.7 |
| surface | `#141925` | 222.4 |
| surface2 | `#1C2231` | 222.9 |
| border | `#252C3D` | 222.5 |
| text | `#F2F5FA` | 217.5 |
| text2 | `#8C95A8` | 220.7 |
| text3 | `#5A6275` | 222.2 |
| accent | `#5AC8FA` | 198.8 |

Seluruh aplikasi hidup di **irisan 28 derajat** roda warna. "Netral"-nya bukan
netral, itu ramp biru-slate. Aksennya cyan. Dark slate + cyan adalah kombinasi
paling padat di dashboard AI, produk crypto, dan dev tool.

Tambahan: `doneInk` `#4ADE80` **identik dengan Tailwind green-400**, bukan
sekadar mirip. Itu tanda warnanya diambil dari ramp bawaan, bukan dipilih.

Pertanyaan kunci core antislop: *kalau logo dan nama produk diganti, apakah
desain ini masih terasa punya karakter sendiri?* Untuk palet ini: tidak.

Catatan proses: saya memberi keringanan karena "warnanya dari artboard Pen".
Itu salah. R-37 justru berkata kalau arah desain sendiri membawa pola slop,
sebut tabrakannya dan serahkan putusan ke pemilik desain — jangan diloloskan
diam-diam, jangan pula ditimpa diam-diam.

**Konsekuensi yang harus disadari:** memperbaiki ini berarti aplikasi berbeda
dari artboard Pen, atau Pen-nya diubah dulu. Itu putusan hariz, bukan saya.

### MEDIUM

**10. Dynamic Type belum dijaga — R-03, C-4**
134 `fontSize:` tetap berpasangan dengan 32 container tinggi tetap, tanpa clamp
`textScaler`. Belum terbukti rusak: percobaan `simctl ui content-size` tidak
menembus ke Flutter di mesin ini, jadi ini **risiko, bukan cacat terkonfirmasi**.
Perlu dites lewat widget test dengan `TextScaler` besar.

**11. Ikon dari satu library default — R-04**
Seluruh app memakai Material Icons apa adanya. Relevansinya masuk akal
(dumbbell, timer, kalender), tapi pilihan set-nya belum ditulis alasannya, dan
Pen tidak menentukan ikon. Ini yang membuat baris setelan terasa generik.

### LOW

**12. Kartu statistik beranda seragam — R-14**
Tiga `_StatTile` ukuran, padding, dan bentuk identik. Volume, e1RM, dan jarak
hari bukan tiga hal yang sama pentingnya, tapi tampil setara.

**13. Header layar seragam — R-05**
Setiap tab membuka dengan `ScreenHeader` + SegmentedTabs/kartu dengan komposisi
yang sama. Untuk dial RHYTHM 2 ini di batas bawah; sesuai kalau memang disengaja.
